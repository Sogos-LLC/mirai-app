⚠️ Internal Data Only Constraints

  • AI forbidden from adding information not in source documents
  • No made-up examples, facts, statistics, or explanations
  • No domain-specific defaults (e.g., no coding examples unless source is about coding)
  • Course size adapts to available content - fewer lessons if limited material
  • Quality over quantity - smaller accurate courses beat hallucinated ones

🧠 Embedding Model

all-MiniLM-L6-v2 via custom embedding service. Generates 384-dimensional vectors for semantic similarity search.

🗄️ Vector Database

Qdrant stores embeddings with metadata (tenant_id, session_id, source_id). Cosine similarity for retrieval.

✨ Generation Model

Google Gemini with per-tenant API keys. Structured JSON output with strict RAG-grounding prompts.

📦 Content Storage

MinIO (S3-compatible) for course content JSON. PostgreSQL for metadata and document indices.
